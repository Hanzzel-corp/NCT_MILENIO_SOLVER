# Guía de Contribución

¡Gracias por tu interés en contribuir al NCT Visual Engine!

## Cómo Contribuir

### Reportar Bugs

Si encuentras un error, por favor abre un **Issue** con:
- Descripción clara del problema
- Pasos para reproducirlo
- Versión de Python y NumPy utilizadas
- Mensaje de error completo (si aplica)

### Sugerir Mejoras

Las sugerencias son bienvenidas. Abre un Issue etiquetado como `enhancement` describiendo:
- La mejora propuesta
- Caso de uso
- Posible implementación

### Pull Requests

1. **Fork** el repositorio
2. **Crea una rama** (`git checkout -b feature/mi-mejora`)
3. **Haz commits** descriptivos
4. **Push** a tu fork (`git push origin feature/mi-mejora`)
5. **Abre un Pull Request**

#### Estándares de Código

- Python 3.8+ compatible
- Seguir PEP 8
- Incluir docstrings para funciones nuevas
- Mantener compatibilidad con NumPy 1.20+

### Áreas de Interés

- [ ] Nuevos formatos de exportación
- [ ] Visualizaciones adicionales
- [ ] Optimización de algoritmos
- [ ] Documentación y traducciones
- [ ] Tests unitarios

## Código de Conducta

- Sé respetuoso en las discusiones
- Foco constructivo en las revisiones
- Reconoce el trabajo de otros

## Preguntas

Para dudas generales, usa el canal de Discussions del repositorio.

---

**Nota:** Este es un proyecto conceptual. Las contribuciones deben mantener el carácter demostrativo del motor.
